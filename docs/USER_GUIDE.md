# RxLite user guide

1. Open the application and create a strong local vault password.
2. Go to Settings and enter the doctor's name, qualifications, BMDC number and chamber details.
3. Register a patient from Patients.
4. Open the patient and choose New prescription.
5. Search the catalogue or add a medicine manually.
6. Enter medicine strength, dose, route, frequency, duration and instructions.
7. Select Traditional Rx or Modern structured layout.
8. Review the preview carefully and print or save as PDF.
9. Download encrypted backups regularly and store them in a secure location.

Do not use a shared device without securing the operating-system account. Losing the vault password without a backup may make the data unrecoverable.
